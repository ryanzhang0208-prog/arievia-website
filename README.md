# arieviafoundation.com

Website of Arievia Foundation, a New York nonprofit offering free public education in English and Chinese.

Static site (plain HTML, CSS, and a little JavaScript), hosted on GitHub Pages.

- `index.html`: English home page
- `zh/index.html`: Chinese home page
- `assets/css/style.css`: styles
- `assets/js/site.js`: motion (the site works without it)
- `assets/img/`: photos and icons
- `CNAME`: custom domain

Preview locally: run `python3 -m http.server 8080` in this folder, then open http://localhost:8080.
